# UAI CHEGUEI

## Projeto Integrador — 1º DSB

O **UAI CHEGUEI** é um projeto desenvolvido como parte do **Projeto Integrador do primeiro DSB**. A proposta é apresentar a identidade e a experiência visual de uma plataforma de delivery, com foco em conectar clientes a opções de comida e organizar as diferentes áreas do serviço.

Este repositório reúne os arquivos do projeto, incluindo as páginas do site, os estilos visuais e os recursos gráficos utilizados na interface.

## Estrutura do projeto

| Arquivo ou pasta | Descrição |
| --- | --- |
| `index.html` | Página de entrada e login |
| `cria.html` | Página de criação de conta |
| `principal.html` | Página principal da plataforma |
| `carrinho.html` | Página do carrinho |
| `redefinir_senha.html` | Página de redefinição de senha |
| `intranet_adm.html` | Área administrativa |
| `intranet_entregador.html` | Área do entregador |
| `uai.css` | Folha de estilos do site |
| `imagens/` | Logotipos, símbolos e elementos gráficos da identidade visual |

## Arquivos de imagem

Os arquivos gráficos da pasta `imagens/` usam nomes em português para facilitar a identificação:

- `logotipo-horizontal.svg` — logotipo horizontal principal.
- `logotipo-horizontal-branco.svg` — versão branca do logotipo horizontal.
- `simbolo.svg` — símbolo gráfico principal.
- `simbolo-branco.svg` — versão branca do símbolo.
- `detalhe-chapeu-de-chef.svg` — elemento gráfico de chapéu de chef.

## Como visualizar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto em um editor de código, como o Visual Studio Code.
3. Abra o arquivo `index.html` em um navegador para visualizar a página inicial.

## Observação

Este repositório representa um projeto acadêmico em desenvolvimento. Algumas telas e funcionalidades são demonstrações visuais e podem não possuir integração com um sistema de autenticação, banco de dados ou serviços reais.
